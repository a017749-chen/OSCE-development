# Handbook integration: detailed local OSCE format
Read for the user's full TAME-style Word station or revision of that local format.
This is an adapted local specification, not verification of current national requirements. User/institutional instructions override these defaults. The 2026-08-18 reference remains historical; do not combine incompatible layouts silently.

## Design evidence
Reuse answered learner/assessment-objective/competency questions; ask only material missing items.
Record a self-contained design brief and alignment table: learner/prerequisites/exclusions; ability stated as condition + observable behavior + standard; task; score anchors; SP/examiner evidence; pilot feedback.
Every scored item maps to a competence and each intended competence has observable evidence. Do not label a disease name as a competency.
If teacher/framework alignment is unverified, label it pending. AI walkthrough and representative human pilot are distinct; no formal trial-readiness claim without the required human evidence.

## Local full-station defaults
- Five sections in order: 一、告示牌; 二、考生指引; 三、評分表; 四、考官指引; 五、SP 指引（劇本）.
- Usual local time: 8 minutes, unless specified otherwise.
- Sign: follow the maintained SKILL.md font specification (48/36 pt); obsolete 36/24 pt examples are historical only.
- Candidate: brief role/setting; three red bullet tasks for this format; explicit exclusions/time; 3x2 relevant-report table when applicable. Reveal neither diagnostic answer nor scoring key.
- Scoring: header plus N items in an (N+1)x5 table; total N*2. N follows the blueprint and SKILL.md. Include candidate ID, station type, difficulty rating, five-level global rating and examiner signature.
- Mark 2–5 intended higher-discrimination items; this is design intent, not empirical item-discrimination evidence. At most one generic item, most items on the main construct; no more than three sub-behaviors per item. All anchors are mutually distinguishable and observable.
- Examiner: five purpose/standardization prompts; setting, case, equipment, expected reasoning/actions, all item-specific anchors and SP summary.
- SP: preparation/rehearsal, setting/posture/affect, personnel/props, timing, volunteer-vs-prompt boundaries, narrative and dialogue table (history component | candidate question | SP response).
- Every SP-dependent score maps to a standardized response. Define sensitive-cue triggers; local limits are <=5 active SP questions, <=3 cue cards, <=3 A4 attachment pages (text preferably <=2).
- Communication stations include teach-back where it tests the intended competency. Technical and physical-examination stations need explicit safety, consent and simulation limitations.

## File and readiness checks
For this local layout, default A4, 2 cm margins, 12 pt body unless a supplied template differs.
Parse the produced DOCX for headings/order, table dimensions, scores, anchors and dialogue coverage. Render and inspect every page separately from structural checks.
Record case consistency and realistic timing, plus whether representative candidate/SP/examiner pilot occurred. Missing human pilot or rendering remains an explicit readiness limitation, not a reason to pretend it ran.
Do not kill the user's Word session. Do not invent data or remove intentional unresolved placeholders to pass QA.
