# OSCE 試題開發

OSCE 是表現本位評量：對齊 `能力 → 任務 → 可觀察行為 → 評分 → SP／考官標準化`，
並讓站次在該學員程度與時間內可行。

三階段：**階段一** 出題前確認（藍圖確認卡）→ **階段二** 草擬五大部分 → **階段三** 產出 Word 並檢核。
需要細節時才讀：敘事醫學規準全文 `references/narrative-rubric.md`；
Word 產檔 `references/docx-word-com.md`；手冊版在地規格 `references/handbook-integration.md`。

## 第一原則

- 測考生能**做什麼**，不是知道什麼。情境不超出該層級可合理處理的範圍。
- **8 分鐘可完成**：劇本不過長、資料不過多，不要求完整診斷處置流程。
- **站型乾淨**：除非刻意設計，不混合不相容站型。
- **評分可觀察**：每項都是考官／SP 能可靠判斷的具體行為。
- **保密**：不放真實病人識別資料或機構敏感細節。

**條列式評分（醫學系預設）**

- 共 **N 項**，N 於階段一確認（國考型建議 15 項，其他 10–15 項）；每項 0 沒有做到／1 部分做到／2 完全做到，**滿分＝N×2 分**。
- ★高鑑別力 **2–5 項**；共通／通用項目 **≤1 項**；主要評分範圍 **≥50%**（至少 ⌈N/2⌉ 項，N=15 時 ≥8）；子項目 **≤3**。
- 病史站 LQQOPERA 群組 **≤30%**（N=15→≤4, N=12→≤3, N=10→≤3）。
- 評分表欄位：`評分項目（共 N 項） | 0 沒有做到 | 1 部分做到 | 2 完全做到 | 註解`，欄寬 8.0 / 1.6 / 1.6 / 1.6 / 1.4 cm。官方範本預印「滿分：30分」只對應 15 項，N 不同時務必改寫。
- 整體表現 5 等第：差1分／待加強2分／普通3分／良好4分／優秀5分。

**敘事醫學評分（非醫學職類可選）**

- 每個計分向度四級：優異（4分）／熟練（3分）／發展中（2分）／未達標準（1分）；**滿分 12 分**。
- 向度1：全心傾聽與病患故事探索（Attention: Eliciting Illness Narrative）——能否辨識病人隱含的情緒暗號（Cues），探詢疾病對日常生活、家庭角色與心靈負擔的衝擊，營造安全包容的傾聽氛圍。
- 向度2：同理共鳴與處境再現（Representation: Empathic Resonance & Reflection）——能否以反思性同理精準回饋病人的焦慮與脆弱，讓病人感受到自己的痛苦被看見與理解。
- 向度3：關係締結與共同照護同盟（Affiliation: Relational Alliance & Shared Care）——能否平權互動、尊重病人價值觀，把專業建議融入病人真實生活，締結可行的照護同盟。
- 向度4：考官質性敘事觀察與反思回饋（Narrative Observation & Qualitative Feedback）——考官記錄關鍵互動片段（Critical Incidents）與反思引導回饋（Reflective Feedback），作為測驗後 debriefing 教材。**不計分。**
- 另附整體表現 5 等第。規準全文見 `references/narrative-rubric.md`。

**SP 提問**

- SP 主動提問 **≤5 題**，其中會觸及評分項目的 **≤2 題**。
- 提問押在**考生完成主要說明之後**（或明顯停頓時），SP 不得主導會談。
- 劇本對白例句表（三欄：`病歷架構 | 醫師對 SP 說的話 | 第三欄`，第三欄依官方範本：病史詢問「SP 的回應」；身體檢查「SP 的回應」；醫病溝通與衛教「SP 的回應或提問」；病情解釋及臨床處置「SP 的回應或提問」，欄寬 3.5 / 6.5 / 5.5 cm）至多 **2 列**寫成提問，其餘列只寫「回應」。
- 提問若觸及評分項目，評分說明須註明「經 SP 提問後才說明者，最多給 1 分（部份做到）」。

**站型紅線**

- **病史詢問站**：LQQOPERA 群組 ≤30%，把分數留給鑑別線索、危險因子、ICE。
- **身體檢查站**：腹部依 視診→聽診→叩診→觸診（**聽診在叩、觸之前**）。
- **醫病溝通與衛教站**、**病情解釋及臨床處置站**：**Teach-back 不可省略**。
- 全部站型：8 分鐘可完成；鑑別診斷 ≥3 個；提示卡 ≤3 張；檢查報告 A4 ≤3 頁（純文字 ≤2 頁）；考生指引測驗主題 ≤3 個紅色 ●；背景資料與告示牌病患資訊各 ≤30 字；不放真實病人識別資料。

## 階段一：出題前確認

**先對話、再產出。** AI 自行假設職類、評分模式、站型、診斷、項目數，老師事後才發現方向不對，整份就得重做。

### 閘門

- 預設先對話再產出；使用者明確說「不用問、直接產」才略過，並在藍圖卡列出採用的設定。
- **已提供的不重問**，只問缺漏或前後矛盾。
- 產出目標有兩種：**A** 在本對話中直接產出教案；**B** 訪談後產出一份《OSCE 專屬出題 Prompt》讓老師帶去其他 AI 平台。
- 產出層級：討論用草稿／完整可印教案／**僅依檢核表審閱既有教案**（審題時跳過訪談，直接到品質檢核閘）。

### 提問風格

- 分輪，**每輪一次問完**（最多 4–5 題），編號呈現，每題附選項或建議預設值；老師可只回數字或「用預設」。
- 環境有選項式提問工具（AskUserQuestion）時，用它呈現可列舉參數（職類、評分模式、站型、學員程度、場景、項目數）；否則用編號清單。
- 老師答不出來時（最常見：鑑別診斷、核心任務、評量目標），**主動提 2–3 個草案讓他挑**，不要空等。
- 扮演資深審題委員，追問情境邏輯，不接受空泛回答。

### 各輪要問的

**第 0 輪 — 分流**：職類（醫學系／各醫事職類）；評分模式（醫學系預設條列式；非醫學職類可選條列式或**敘事醫學**）；產出目標 A／B；產出層級。

**第 1 輪 — 站次定位**：站型、學員程度、科別與主題／主訴、場景。

**第 2 輪 — 評量設計**：主要評量目標（一句話）、8 分鐘核心任務、主診斷／照護焦點＋鑑別或生活脈絡（≥3）、目標能力；
條列式問**項目數 N** 與想考的★重點；敘事醫學問病人生活世界裡的情緒暗號（cues）與期待的照護同盟。

**第 3 輪 — 執行**：必要人員、道具、檢驗報告；預估難度與過關意圖（可選）。

### 項目數 N 怎麼問

- 真正固定、不必問的只有：測驗時間、每項 0/1/2 三級、五大部分結構。**項目數與滿分不在此列。**
- 問法：「這一站要出**幾項**評分項目？（國考型建議 15 項；其他考型 10–15 項）」
- 未指定且使用者授權採預設時，於藍圖卡明列 N＝15 後繼續。
- 比例型規則隨 N 換算，並在確認卡寫出實際數字（例：N＝12 → LQQOPERA ≤3、主要範圍 ≥6）。

## 階段二：草擬

### 0. 先讀格式範本

正式產出前讀對應站型的 TAME 範本（檔名見上方硬規格的「範本檔名」）。
路徑依序：使用者指定 → 部署產生的 `deployment.local.json` 的 `template_dir` → repo 的 `templates/`。
先確認檔案存在並記下實際來源；不可假設相對於 skill 的 `../../templates` 存在。
站型不在四種內時，說明最接近哪一種、做了哪些調整。早期腦力激盪可略過。

### 1. 評量藍圖
站名、站型、學員程度、時間、場景、目標能力、過關意圖；一句話寫主要評量目標；對應能力框架。

### 2. 臨床情境
一個聚焦的主訴；資料足夠完成任務但不過度暴露；年齡、性別、生命徵象、病程、檢驗、檢查發現、預期處置彼此吻合。

### 3. 五大部分

1. **告示牌**：站次號＋病患資訊。
2. **考生指引**：背景資料＋測驗主題（紅色 ●）＋時間＋相關檢查報告表格（生命徵象／主要症狀／「須由考生自行詢問」的病史與用藥）。
3. **評分表**：條列式（N 項＋整體表現）或敘事醫學（規準表＋質性回饋表＋整體表現）。
4. **考官指引**：固定 5 條任務提示、場景與 SP 起始姿勢、病情摘要、鑑別（依可能性排序）、道具、**每項評分說明（三等級）**、SP 劇本摘要。
5. **SP 指引**：場景、起始姿勢、情緒（x/10）、表情、肢體、說話風格、人員道具（紅字）、回應原則、劇情摘要、**三欄對白表**、**診間示意圖**（拉簾、診助、考官、SP、考生位置）。

### 4. 評分設計

**條列式**
- 每項寫**可觀察的具體行為**，不用「適當地」這類形容詞；三級錨點彼此可區分。
- 不重複給分；不需要隱性推論才能評。
- 站型骨架（N＝15 為例，按比例調整）：
  - 病史：開場 1 → LQQOPERA 群組（合併計分）→ 過去病史 1 → 藥物／過敏 1 → 家族 1 → 社會／旅遊 1 → 系統回顧 1 → 作結／ICE 1 → 主題特異★ 4–5
  - 身體檢查：基本態度 2 → 視診 1–2 → 依序系統檢查 4–6 → 診斷特定徵象 4–6 → 口頭報告 1–2
  - 醫病溝通：關係／同理 2 → 確認理解 1 → 衛教內容 6–8 → **Teach-back 1** → 結尾 2–3
  - 病情解釋：準備 1 → 告知 3–4 → 解釋診斷／檢查／處置 4–5 → 共同決策 2–3 → Teach-back＋結尾 2

**敘事醫學**（非醫學職類的全人溝通、衛教、照護）：不做破碎的 0/1/2 打勾，改用 Charon 的 Attention／Representation／Affiliation 質性規準，加考官質性回饋。**錨點全文讀 `references/narrative-rubric.md`。**

### 5. SP 行為

- 身份、情緒、痛苦程度、說話風格、界線；**明示可說／可做、不可說／不可做**。
- 每個 SP 面向的評分項目都有對應的 SP 回應。
- SP 的提問是**測驗工具不是引導工具**，推進會談的必須是考生。會送分的提問（評分表有「說明手術風險」，SP 就問「開刀有什麼風險？」）要省著用。
- 提問測**回應品質**（情緒、擔憂、價值偏好，如「我要顧小孩，沒辦法住院太久」），不替考生補內容；觸發條件寫清楚時機。
- 對白表第三欄最容易被寫成列列發問——那會訓練 SP 主導會談。
- SP 劇本摘要同時放在考官指引末尾。

### 6. 考生指引
說明角色、場景、任務、時間、可用資源；**不洩漏評分用語**；不評分的領域要寫明（例：「本站不評分身體檢查」）；有無助理或模型要寫明。

### 7. 資料與道具
難以模擬的徵象用圖片；報告含有意義的陽性與陰性發現，避免大量無關正常值。

## 站型注意事項

- **病史**：評資訊蒐集、時序、危險因子、症狀與疾病連結、摘要轉場；避免「詢問相關症狀」這類空泛項目；SP 以被動回應為主。
- **身體檢查**：考生指引明示部位／系統與不評分項目；步驟聚焦可觀察，避免「腹部檢查表現良好」；助手、姿勢、覆蓋、隱私要寫明；無法模擬的異常用圖或報告並定義考生如何詮釋。
- **醫病溝通與衛教**：評關係、議程、同理、分塊、確認理解、回應情緒、結尾；禮貌項不主導評分。評的是考生能否**主動、有結構地衛教**；SP 一直問，考生被動接話就能拿分。
- **病情解釋／臨床處置**：評解釋、不確定性、下一步檢查、安全議題、治療選項、追蹤；任務不能變成朗讀結果。SP 一開場就問「要不要開刀？」「有什麼風險？」，等於把三個評分項直接餵給考生。
- **技術／處置**：安全、身份、同意、準備、無菌、關鍵步驟、完成、併發症處置；有先後順序就標明；附設備清單與示意圖。

## 階段三：產出 Word 並檢核

工具在 OSCE-development repo 的 `scripts/`；repo 位置是 `deployment.local.json` 裡 `canonical` 的上一層。

1. **把教案內容寫成 YAML**，格式照 repo 的 `examples/example_station.yaml`（只放內容；字級、欄寬、固定文字都由 `rules.yaml` 決定）。
2. **產檔**：`python scripts/build_station.py <教案.yaml> -o <runtime_dir>/<檔名>.docx`
   —— 依站型取官方範本的版面與樣式，任何電腦都能跑，不需要 Word。違反硬規格（字數、● 數、★ 數、SP 提問列、Teach-back、鑑別數）會直接拒絕並列出原因。
3. **檢核**：`python scripts/validate_station.py <檔案>.docx` —— 必須零 FAIL；WARN 要逐一說明理由。
4. **逐頁看**：有 Word 就轉 PDF 看每一頁（表格框線、跨頁、切邊只有看得出來）；沒有 Word 就明說版面尚未目視確認。
5. 存到輸出位置：使用者指定優先，否則 `deployment.local.json` 的 `output_dir`。

- 檔名：`科別_主題_站型_OSCE試題_vN.docx`，正體字。**同名檔存在就用新版號，工具本身也拒絕覆蓋**；使用者手改過的檔案不重新產生。
- 審閱既有教案：直接跑第 3 步。`stations/STATUS.md` 是既有 16 份的檢核結果。

## 品質檢核閘（產出前逐項確認）

- **站次**：已記錄藍圖與使用者設定？8 分鐘可完成？符合學員程度？站型乾淨？
- **評分**：全部可觀察？項目數與藍圖卡一致、滿分＝N×2？★、共通、主要範圍、子項目、LQQOPERA 符合換算後的數字？錨點清楚？每個 SP 面向項目都有 SP 回應？
- **SP**：提問總數與送分題在上限內？對白表提問列在上限內、其餘只寫回應？提問押在考生說明之後？送分題的評分說明已註明上限？
- **考生指引**：紅色 ● 在上限內？未洩漏評分？提示卡與報告頁數在上限內？
- **格式**：字級符合硬規格？背景與告示牌字數？鑑別 ≥3？Teach-back、IAPP？三欄對白表？考官指引含評分說明＋SP 摘要？SP 指引含診間示意圖？表格置中且總寬在上限內？

## 偏好的輸出順序

討論草稿：藍圖 → 考生指引 → 考官指引與流程 → SP 設定與劇本 → 道具／報告 → 評分表＋說明 → 審閱筆記與待釐清問題。
正式教案另加：封面 metadata、情境摘要、場地設置檢核表、時間與人員角色、SP 訓練檢核表、附件。

## 修訂風格

先保留臨床意圖，再修可行性與評分信度；**收緊模糊項目，而非加更多項目**；站次過大就拆站；
不確定時**標為待討論**，不要自行編造高利害臨床細節。
