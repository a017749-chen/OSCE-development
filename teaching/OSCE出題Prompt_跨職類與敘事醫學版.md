# OSCE 出題 Prompt 範本｜跨職類與敘事醫學評分專用版

本範本專為**非醫學職類（護理、藥學、物理治療、職能治療、呼吸治療、營養、社工、臨床心理、醫技等）**及**跨領域團隊照護（IPE/IPCP）**出題教師設計。

提供兩種評分模式：
1. **模式 A：敘事醫學方式評分（推薦：全人照護四大向度質性規準＋考官質性觀察回饋）**
2. **模式 B：專業條列式評分（TAME 風格 0/1/2 分）**

---

## 使用說明

1. 複製下方「可直接複製的 Prompt 區塊」。
2. 將每一行「`--`」替換為您的教案背景與臨床設定；未確定的留「`--`」即可，AI 將主動協助推論補齊。
3. 貼入任何支援繁體中文的 AI 平台（Claude、ChatGPT、Gemini 等），即可直接產出符合 TAME 格式的五大部分完整教案。

---

## 可直接複製的 Prompt

```markdown
幫我出一題符合專業標準與台灣醫學教育學會（TAME）格式的 OSCE 教案。

【一、職類與核心定位】
- 考評職類：--（例：護理師／藥師／物理治療師／呼吸治療師／營養師／社工師）
- 評分模式：--（填寫「敘事醫學方式評分」或「條列式評分」）
- 站型：--（例：醫病溝通與衛教／全人照護與病情解釋／臨床處置與用藥指導）
- 學員程度：--（例：新進人員／實習生／二年期學員／PGY）
- 科別與主題：--（例：護理部慢性病自我管理／藥學部高風險用藥諮詢／復健科中風賦能）
- 病患主訴與年齡性別：--（≤30字，包含生活困擾）
- 測驗場景：--（門診／病房／衛教室／處置室／居家訪視）
- 測驗時間：8 分鐘

【二、評量設計與核心目標】
- 主要評量目標（一句話，考生要能做到什麼）：--
- 考生核心任務（8分鐘內完成）：--
- 目標能力領域：--（全人照護／同理溝通／專業技能／病人安全／關係締結）
- 臨床焦點／主要照護難題：--
- 重要生活脈絡或共病情境（≥3項）：--

【三、臨床素材與生活世界（Lifeworld）】
- 關鍵生活病史與照護困難線索：--
- 重要檢查發現（陽性／陰性）：--
- 診間文件或檢驗報告：--
- 高鑑別力（★）考核重點：--
- 病患／家屬隱含的情緒暗號（Cues）：--

【四、執行人員與 SP 設定】
- 必要人員與道具：--（SP／考官／家屬／專業器材／衛教模型）
- SP 人設與情緒起始狀態：--
- SP 提問限制：主動發問 ≤ 5 題（觸及評分項目者至多 2 題）；提問一律押在考生說明告一段落後；不可讓 SP 主導會談。三欄劇本對白表中主動提問列至多 2 列，其餘一律只寫「回應」。

【五、評分架構要求】
若選「敘事醫學方式評分」：
請依 Rita Charon 敘事醫學四大核心向度輸出全人照護質性評量規準（Holistic Rubric，各向度附優異4分／熟練3分／發展中2分／未達標準1分錨點），並附「考官質性敘事觀察與反思回饋表」與「整體表現 5 等第」：
1. 向度一：全心傾聽與病患故事探索（Attention: Eliciting Illness Narrative）
2. 向度二：同理共鳴與處境再現（Representation: Empathic Resonance & Reflection）
3. 向度三：關係締結與共同照護同盟（Affiliation: Relational Alliance & Shared Care）
4. 向度四：考官質性敘事觀察與反思回饋表（記錄關鍵互動 Critical Incidents 與質性反思建議）

若選「條列式評分」：
請輸出 N 項（自訂 10–15 項，每項 0 沒有做到／1 部分做到／2 完全做到，滿分 N×2 分），含高鑑別力★ 2–5 項、主要範圍 ≥ 50%、整體表現 5 等第。

【六、教案輸出格式（TAME 五大部分）】
請以繁體中文完整輸出教案五大部分：
1. 告示牌：站次號（48pt粗體）＋病患資訊（36pt粗體，≤30字）。
2. 考生指引（本體26pt）：背景資料（≤30字）＋測驗主題（≤3個紅色●）＋時間8分鐘＋相關報告（14pt）。
3. 評分表：依上述評分模式輸出表格。
4. 考官指引：考官任務提示＋場景設定＋病情摘要＋評分錨點說明＋SP劇本摘要。
5. SP 指引：演出說明＋回應原則＋劇情摘要＋劇本對白例句（三欄表格）＋診間示意圖。
```

## 已填寫範例（非醫學職類 · 敘事醫學評分範例）

```markdown
幫我出一題符合專業標準與台灣醫學教育學會（TAME）格式的 OSCE 教案。

【一、職類與核心定位】
- 考評職類：護理師（二年期護理師 N2 評核）
- 評分模式：敘事醫學方式評分
- 站型：醫病溝通與衛教站
- 學員程度：新進兩年期護理師
- 科別與主題：外科病房 腸造口術後自我照護衛教與心理調適
- 病患主訴與年齡性別：52歲男性，直腸癌術後造口第4天，對造口充滿抗拒且不願直視傷口
- 測驗場景：一般外科病房
- 測驗時間：8 分鐘

【二、評量設計與核心目標】
- 主要評量目標：能敏銳察覺造口病人對身體心像改變之恐懼，運用反思性同理建立照護同盟，循序引導病人接納造口照護
- 考生核心任務：評估病人心理接納度、同理其焦慮與家庭角色衝擊、進行造口袋清潔衛教並確認理解
- 目標能力領域：全人照護、同理溝通、專業技能、關係締結
- 臨床焦點／主要照護難題：人工造口身體心像紊亂、害怕異味與他人異樣眼光、擔心無法重返職場
- 重要生活脈絡或共病情境：身為家中經濟支柱、平時生活自尊心強、妻子在旁照顧但病人不願讓妻子看見造口

【三、臨床素材與生活世界（Lifeworld）】
- 關鍵生活病史與照護困難線索：曾從事業務工作，極度在意外觀與味道；換藥時總是將頭轉向另一側
- 重要檢查發現：造口黏膜紅潤、血循良好，周圍皮膚輕微發紅，造口底座已使用48小時需更換
- 診間文件或檢驗報告：病歷生命徵象平穩、護理記錄載明前次換藥病人曾暗自啜泣
- 高鑑別力（★）考核重點：能否停下機械式衛教，接住病人的情緒脆弱點；能否與病人共同商討逐步面對造口的步調
- 病患／家屬隱含的情緒暗號（Cues）：「這個袋子黏在肚子上一輩子，我跟廢人有什麼兩樣…」

【四、執行人員與 SP 設定】
- 必要人員與道具：SP（配戴腹部模擬造口模型）、考官、造口袋衛教模具組、生理食鹽水、棉籤
- SP 人設與情緒起始狀態：神情抑鬱，躺在病床上眉頭深鎖，考生走近時雙手下意識用被單遮掩腹部造口
- SP 提問限制：主動發問 ≤ 5 題；提問押在考生說明後；對白表中提問列至多 2 列。

【五、評分架構要求】
採用「敘事醫學方式評分」，產出四大向度質性規準（優異/熟練/發展中/未達標準）＋考官質性觀察回饋表＋整體 5 等第。

【六、教案輸出格式】
完整輸出告示牌、考生指引、評分表、考官指引、SP指引（含診間示意圖）。
```
